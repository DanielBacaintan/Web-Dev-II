# Elsewhere — Travel and Places

A responsive travel inspiration page for curious people who like to take the scenic route. Browse a few destinations, read a note about slower travel, and try the postcard signup form.

## Run the page

Open `index.html` in a browser. 

## What I learned

It was straighforward to build Elsewhere when I had a clear visual idea of the development. Semantic HTML made every piece of the page meaningful and CSS Grid and Flexbox allowed to make the destination cards and page parts simpler to position. The hardest thing was how to make the layout appear balanced on a small phone screen and maintain the spacious appearance on desktop. I had to apply media queries to alter the navigation and stack the destination cards with smaller screens. Mobile menu and signup feedback also allowed me to exercise JavaScript events and the DOM update. I tested the page with phone and desktop widths and made adjustments thereof. On the next course, I would prefer sharpening my knowledge about JavaScript, in particular, making forms more resilient and relating them to actual services.
