I found creating the Elsewhere website using semantic HTML simple as it allowed me to split up the content into logical parts for the organization of the site. Creating the destination card styles with CSS Grid and Flexbox were easy enough. However, creating a consistent design across both desktop and mobile devices was difficult. Creating media query adjustments to change spacing, navigation, and image sizes was time consuming. Creating JavaScript interactive elements were also time consuming and needed more attention, such as updating the mobile menu and providing users with feedback on form submissions. In my Web Development II module, I want to develop my knowledge of JavaScript further; specifically form validation, in order to create better-built, and more interactive sites.
